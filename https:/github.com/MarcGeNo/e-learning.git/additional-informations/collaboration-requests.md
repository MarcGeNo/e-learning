# Collaboration Requests

Joint collaboration is crucial in achieving a living wage for workers across the world.

The _Collaborations_ function allows sharing data in a secure way eliminating the need for manual export extraction and external workflows, thus saving valuable time and safeguarding data privacy.&#x20;

Buyers can initiate invitations to suppliers directly from the Salary Matrix. Suppliers receive a request to connect and share their data only after a explicit consent.

<details>

<summary><strong>Data Privacy</strong></summary>

We’ve built this feature with strong data privacy protections to ensures a secure, transparent, and user-controlled data exchange process:

* **Secure request validation**: buyers must provide two valid data points, either "Facility ID + user email" or "Facility ID + Matrix ID"—both of which originate from the supplier. If these details don’t match, the request cannot be sent, ensuring only authorized connections are attempted.&#x20;
* **Explicit consent is required before any data is shared**: this consent request is built into the invitation request. No raw data is ever shared without the user first approving.
* **Data ownership remains fully with the supplier:** the user has the right to grant and revoke access at any time even once consent is first given.

</details>

{% step %}
### Receive Invite

If you have been invited by a Buyer you will receive an email notification.&#x20;

Clicking the link will take you to the Salary Matrix, where you will need to log in.&#x20;

{% endstep %}

{% step %}
### Go to Collaborations Tab

A new item _Collaborations_ will be visible to you in the left navigation panel if you have received an invite from a buyer, including a counter with the number of new requests..&#x20;

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-06-15 a les 11.28.11.png" alt=""><figcaption></figcaption></figure>

Click on Collaborations to see more details about the received requests.&#x20;
{% endstep %}

{% step %}
### Check Request Details

Check that this is a valid buyer in your supply chain and the date range they have requested the connection for.&#x20;

Click on the arrow next to ‘What the Buyer Will See’ to see the details of each data request. Request can include:

* Full Data Visibility or Facility Averages only.
* Consent to Share with Auditors requested or not.
* Consent to Share Living Wage Contribution Data requested or not.

{% endstep %}

{% step %}
### Approve or Decline

Once you have checked the details you can select ‘Approve’ or ‘Decline’.&#x20;

When you decline you will be asked to share a reason to give the buyer context. In case you agree with the overall request but there is a specific detail you do not accept, it is recommended to decline with reason, so the buyer can send you an updated request.
{% endstep %}
