# Troubleshooting

<details>

<summary><strong>UNABLE TO LOG-IN</strong></summary>

&#x20;If you are unable to log in, click on “Forgot your password?” and follow the process to reset it.

Once you have successfully logged in, please click the “Verify” button.

It is important that you are logged into your email account before accessing the log in link; otherwise, the system will not be able to send the verification email.

</details>

<details>

<summary><strong>EXCEL UPLOAD FAILURE</strong></summary>

Here are the most frequent reasons why the Excel upload can fail and how to correct the problem:

| Potential Reasons                                                                 | How to solve it                                                                                                                                                                   |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Old template used                                                                 | Make sure to download the latest template from the platform                                                                                                                       |
| Changes in the format of the file or cells                                        | Make sure that there have been no changes in the format of the file (added, duplicated or deleted columns, added pages…) or cells (drop-down lists format removed).               |
| Using links to external data                                                      | Make sure that values are entered in the numerical fields and not formulas or links to external data. Copy/paste values only.                                                     |
| Excel file being open while uploading                                             | Make sure the Excel file is not in use while uploading the data                                                                                                                   |
| Symbols in numerical fields with no value                                         | Leave the fields with no value empty or enter 0                                                                                                                                   |
| Active data filtering                                                             | Make sure to remove any data filtering before upload                                                                                                                              |
| Values not included in the drop-down lists and/or removed drop down lists         | Make sure to select one item from the built-in drop-down lists and do not delete the list when entering the data.                                                                 |
| Work area not recognised                                                          | The entered work area is not included in the drop-down list, or it is included in the list, but capital letters have not been used. Select the work area from the drop-down list. |
| Error message: Work area 'abc' is not associated with your facility sector: 'abc' | <p>The values in the excel file aren't matching the Facility's sector. </p><p>Make sure you're selecting the option that starts with "abc" for each row.<br></p>                  |



</details>
