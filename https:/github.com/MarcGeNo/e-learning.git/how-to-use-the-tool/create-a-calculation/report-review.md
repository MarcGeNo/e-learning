# Report review

Before you submit your Calculation you will be able to review the calculated values.

The tool will provide you with a graph illustrating the current wage levels compared to living wage estimate, segregated by gender. Additional reference points will also be shown in the graph.

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-06-05 a les 10.02.13.png" alt=""><figcaption></figcaption></figure>

You can click on any bar of the graph to open a panel on the right describing, step-by-step, how the Wages, Bonuses and In-kind benefites have been calculated.&#x20;

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-06-05 a les 10.03.10.png" alt=""><figcaption></figcaption></figure>

After reviewing the calculations, you can confirm to continue.

{% hint style="info" %}
You can find more information about the calculation formulas of the Salary Matrix [here](../../about-the-idh-salary-matrix/the-formulas.md).
{% endhint %}
