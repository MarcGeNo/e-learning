# Create a Calculation

You can create a “Living wage gap calculation” from the _Facilities_ view or from the _Calculations_ view.

In the _Facilities_ view, click on the Facility of choice and click on the button **Create Living Wage Gap Calculation**_._

In the _Calculations_ view, click on the button **+ Create living wage gap calculation.**
