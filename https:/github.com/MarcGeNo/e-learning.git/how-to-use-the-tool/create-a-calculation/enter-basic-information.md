# Enter Basic Information

When you create a living wage gap Calculation, you will be requested to enter the facility basic information:

![](<../../.gitbook/assets/Unknown image (26)>)

### **Facility**

Select the facility from the drop-down list.

### **Reporting year**

IDH recommends using a reporting period of a full calendar year. However, some certification schemes might ask you to use a production year instead. Therefore, if you use the tool for certification purposes, please confirm with the certification scheme the reporting period to use.

If you select a data year for which a Calculation already exists, the following message will appear: "A living wage gap calculation already exists for this facility and reporting period." In this case, you can only create a new calculation for this facility and year by checking below "_This is a test_" calculation.

### **Minimum number of paid annual leave for a worker**

Enter here the number of hours of paid annual leave and paid annual public holidays (but excluding weekly rest days), that a worker is legally entitled as a minimum each year. This figure is used by the tool to calculate the maximum number of regular working hours in the reporting year (corrected standard work year).

### **Number of hours of unpaid mandatory leave for a worker**

Complete this field only if ALL workers are sent home without pay for a certain period. This might happen if the facility is under an emergency, such as fire, or if the facility is closed to work for flooding, maintenance, or other circumstances.

Enter here the annual number of hours of unpaid mandatory leave that a worker has been obliged to take. For example, if ALL workers were sent home without pay for two weeks and the regular weekly working hours are 48, enter 96.

Unpaid mandatory leave does not include weekly rest days.

### **Required data to proceed**

The tool is designed to work with actual data of hours worked and remuneration paid during a completed year. Therefore, to get accurate calculations, the tool will ask you to confirm that you have the necessary data to proceed. You can only continue with data entry if you check the two boxes below:

![](<../../.gitbook/assets/Unknown image (27)>)

### **This is a test**

Check out this box if you are creating a calculation for test purposes. This will prevent the data from being sent to the IDH database when the calculation is submitted.
