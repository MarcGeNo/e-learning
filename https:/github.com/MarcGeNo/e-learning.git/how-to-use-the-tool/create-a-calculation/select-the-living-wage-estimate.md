# Select the Living Wage Estimate

#### Select a Linving Wage estimate

Next, you will need to select a living wage estimate for your region and reporting period.

![](<../../.gitbook/assets/Unknown image (28)>)

By clicking on the button _Select living wage estimate_, the tool will provide you with a list of available estimates corresponding to the past, current and next year of the reporting period for your country or region, calculated by IDH recognized methodologies.

![](<../../.gitbook/assets/Unknown image (29)>)

You can use the filter options to facilitate your search.

Several reference wage estimates may be available.&#x20;

{% hint style="info" %}
If there are no estimates in the list, please check that your filters are correct.&#x20;

If the filters are correct and there are no estimates available for your region, please get in touch with the [IDH recognised methodologies](https://www.idhsustainabletrade.com/idh-living-wage-identifier/) to find out if they are interested in measuring the living wage for your region of interest.
{% endhint %}

When choosing, pay attention to:

1. **Region**: Choose an estimate that covers your region. Some estimates may refer to a specific product (e.g., coffee or bananas). These are still relevant for any sector, as living wages are not sectoral.
2. **Year**: Select the year corresponding to your payroll data.
3. **Availability** (public or paid): Publicly available reference estimates are free of charge for most regions.
4. **Methodology**: Indicates the estimation methodology. All methodologies included in the Salary Matrix have been recognized by IDH based on 12 criteria.

If you select an Anker methodology (Full-fledged or Reference value) or a Living wage for US estimate, the gross monthly estimate value will automatically be included in the tool. If you select any of the other methodologies, you will have to enter the value manually.

You can access the Living Wage for US public estimates [here](https://www.google.com/maps/d/u/0/viewer?mid=1QFTe0iAk7LGj_tsjDAC8gfm-78a4bQA\&femb=1\&ll=50.688883235458384%2C-112.8810171778265\&z=3).

You can access the Wage indicator public estimates [here](https://wageindicator.org/salary/living-wage/workers-trade-unions). If you need access to old estimates you can request accest to their paid database [here](https://wageindicator.org/work/living-wages/purchase-data/).

You can request access to the Fair Wage Network database [here](https://fair-wage.com/living-wage-database/).

#### Add additional reference values

In case you wish to compare the total comparable remuneration against other references beyond one living wage estimate, you can add up to two additional references of your choice. The reference(s) will not be used for any calculations but will be displayed visually in the graph of your report.
