# Manual data entry vs Excel upload

## Data entering system

You can choose to enter the payroll data manually on the tool or using the Excel template.

To enter the payroll manually, click on the button _+ Add Job category._

To enter the payroll using the Excel upload template, download the latest template, fill in the data and Upload it to the tool by clicking on the corresponing buttons.

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-01-22 a les 17.31.45.png" alt=""><figcaption></figcaption></figure>

<details>

<summary>Manual data entry</summary>

When you neter your paydroll data manually, the tool will show you the status of your payroll data entry by a coloured tag on the right of the top menu:

![](<../../.gitbook/assets/Unknown image (31)>)

To be able to save your data you have to enter at least:

* Job category name
* Work area name
* Number of men and/or of women
* Average of Ordinary hours worked of men and/or women
* Average Wage earned of men and/or women

{% hint style="info" %}
Once this information is entered, the status tag will change to Complete and you will be able to save the Job category but note that you might still need to enter overtime, bonuses and in-kind benefits when applicable.
{% endhint %}

</details>

<details>

<summary>Excel upload</summary>

{% hint style="info" %}
Always download the  Excel upload template from the platform to make sure that you have the latest version.
{% endhint %}

{% hint style="info" %}
Do not make any changes to the format of the downloaded file, otherwise the file will not upload.
{% endhint %}

Complete one row per Job category by each gender.

Once your excel is completed, click on _Upload excel template_ and select the file from your computer.

If you have problems to upload the template, check the troubleshooting section [here](../../additional-informations/troubleshooting.md).

</details>
