# Job categories vs individual workers

You can enter workers grouped in Job Categories, Individually or a combination of both.

{% hint style="info" %}
To enter workers individually, create a Job category with only one worker.
{% endhint %}

<details>

<summary><strong>Entering payroll data by Job Category</strong></summary>

Entering workers grouped in Job categories is recommended for facilities with a simple time-based remuneration system.

If you choose to enter your workers grouped in Job categories, you’ll have to calculate the average for the payroll data entry points. To do so, add up the data point of all workers and divide by the number of workers in the Job Category.

_For example: If there are 20 workers in the Job category, to enter the Ordinary hours worked, add the hours worked by all workers and divide the sum by 20._

While grouping workers in Job categories might save some data entering time, it is important to ensure that there are no substantial variations in wages, bonuses and in-kind benefits between the workers of the Job category since substantial information could be missed due to averaging.

{% hint style="info" %}
Note that it is recommended to enter workers paid by productivity individually, due to the variations in remuneration among the individuals linked to this type of compensation system.
{% endhint %}

Therefore, workers included in one Job category must

* Have the same type of contract
* Do similar work
* Work the same shift pattern
* Have the same CBA protection
* Have roughly earned the same wages (less than 10% difference)
* Have similar productivity
* Have roughly received the same bonuses
* Have roughly received the same In-kind benefits

To facilitate the verification process, use a Job category name that reflects the role of the workers included in the job category.

</details>

<details>

<summary><strong>Entering payroll data By worker</strong></summary>

Entering workers individually is the recommended option since you can enter information taken directly from your payroll system without the need of calculating averages. Also, it provides a very detailed report with a case-by-case analysis.

In this case it is highly recommended to use the Excel upload template to speed up the data entering process. While entering a long list of individual workers in the Excel file might initially take some time, the yearly update of the information is easier than when grouping workers by Job category, since there is no need to re-calculate averages.

To maintain the tracking of each employee, you can use the “Job Category” field to include a worker identifier along with the job category name. For example:\
• Packing – 12345\
• 12345 – Packing

{% hint style="info" %}
Make sure not to use any personal data as identifier!
{% endhint %}

</details>
