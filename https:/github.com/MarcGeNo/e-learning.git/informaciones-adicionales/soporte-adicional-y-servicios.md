# Soporte adicional y servicios

Comuníquese con el servicio de asistencia en livingwagematrix@idhtrade.org para:

* **Preguntas**: si no encuentra respuesta a sus preguntas sobre el uso de la Matriz Salarial o tiene comentarios sobre este sitio de aprendizaje electrónico.
* **Verificación de datos**: para solicitar un presupuesto para verificar los datos ingresados ​​en sus cálculos y detectar posibles errores.
* **Informes agregados**: para solicitar un presupuesto para recibir informes agregados de las instalaciones de su cadena de suministro.
* **Consultoría sobre brechas de salario digno**: para solicitar un presupuesto para obtener apoyo para su programa de salario digno.
