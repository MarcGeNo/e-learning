# Cierre de las brechas

La información de su informe le proporcionará las métricas adecuadas para guiar su programa de cierre de brechas de salario digno.

Por ejemplo, si ha seleccionado la opción "Brecha por unidad comercial" para su informe, esta se incluirá en la sección "Información del producto", lo que le permitirá calcular el importe de la contribución necesaria para reducir la brecha salarial de acuerdo con el volumen comprado.<br>

Para saber cómo puede colaborar con sus socios de la cadena de suministro para reducir la brecha salarial, consulte el [Paso 4](https://www.idhsustainabletrade.com/living-wage-platform/closethegap/) de la hoja de ruta para el salario digno.
