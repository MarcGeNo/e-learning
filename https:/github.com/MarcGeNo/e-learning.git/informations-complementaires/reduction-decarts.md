# Réduction d'écarts

Les informations contenues dans votre rapport vous fourniront les indicateurs clés pour orienter votre programme de réduction des écarts de salariale vital.

Par exemple, si vous avez sélectionné l'option « Écart par unité commerciale » pour votre rapport, cette information figurera dans la section « Informations produit », ce qui vous permettra de calculer la contribution nécessaire pour combler l'écart salarial en fonction du volume acheté.

Pour découvrir comment collaborer avec vos partenaires de la chaîne d'approvisionnement afin de réduire l'écart salarial, consultez [l'étape 4](https://www.idhsustainabletrade.com/living-wage-platform/closethegap/) de la feuille de route pour un salaire décent.
