# Verification des Cálculs

Il est fortement recommandé de vérifier les calculs afin de garantir la validité des données.

Pour plus d'informations sur la vérification des calculs, consultez[ l'étape 3](https://www.idhsustainabletrade.com/living-wage-platform/verifying-calculations/) de la feuille de route pour un salaire décent.

Les [Guidelines for Auditing](https://www.idhsustainabletrade.com/uploaded/2024/10/IDH-Auditing-Guidelines-2024.pdf) établissent les procédures minimales d'audit des données salariales et des écarts de salaire vital, procédures qui ont fait l'objet d'un consensus entre les normes et les systèmes de certification recommandés par l'IDH.

Le [Base Report](https://www.idhsustainabletrade.com/uploaded/2023/05/IDH-Base-report-updated-design-06032023.pdf) constitue la preuve matérielle permettant aux auditeurs de vérifier les données salariales et les calculs des écarts de salaire vital.

La [liste d'Organisations certifiées](https://impactbuying.com/academy/living-wage-training/certified-organisations/) comprend les auditeurs et les inspecteurs ayant suivi avec succès la formation de l'IDH relative à la vérification des écarts de salaire vital, ainsi que leur numéro d'agrément, indispensable à l'émission du Rapport de base de l'IDH.

Si vous prévoyez de vérifier vos calculs d'écart de salarie vital, vous pouvez ajouter des informations complémentaires dans la section « Options complémentaires » de l'outil, afin de contextualiser votre rapport.
