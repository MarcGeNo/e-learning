# Soutien et services

Veuillez contacter le service d'assistance à l'adresse livingwagematrix@idhtrade.org pour :

**Questions** : Si vous ne trouvez pas la réponse à vos questions concernant l’utilisation de la matrice salariale ou si vous avez des commentaires sur ce site d’apprentissage en ligne.

**Vérification des données** : Pour obtenir un devis pour la vérification des données saisies dans vos calculs et la détection d’éventuelles erreurs.

**Rapports agrégés** : Pour obtenir un devis pour recevoir des rapports agrégés de vos sites de chaîne d’approvisionnement.

**Conseil en matière d’écart de salaire vital :** Pour obtenir un devis pour un accompagnement dans le cadre de votre programme de salaire vital.
