# Dépanage

<details>

<summary>Impossible de se connecter</summary>

&#x20;Si vous ne pouvez pas vous connecter, cliquez sur « Oubliez votre mot de passe ? » et suivez le processus pour le réinitialiser.

Une fois que vous vous êtes connecté avec succès, veuillez cliquer sur le bouton « Vérifier ».

Il est important d'être connecté à votre compte e-mail avant d'accéder au lien de connexion ; Sinon, le système ne pourra pas envoyer l'e-mail de vérification.

</details>
