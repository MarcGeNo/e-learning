# Avant de commencer

{% hint style="info" %}
La Matrice Salariale doit être complétée avec les données de production et de salaire de l'année civile la plus récente.

Pour obtenir des calculs précis, il faut :

\- pour chaque travailleur ayant travaillé dans l'établissement pendant la période de saisie des données :

·       Le nombre d'heures travaillées (régulières et heures supplémentaires)

·       Les salaires et primes reçus&#x20;

·       Les avantages en nature reçus

\- pour l'installation

·       Le nombre minimum d'heures de congé annuel payé pour un travailleur

·       Le nombre d'heures de congé obligatoire non rémunéré pour un travailleur

·       Le coût annuel pour l'employeur des différentes prestations en nature par travailleur
{% endhint %}

{% stepper %}
{% step %}
### Crear una cuenta

Pour accéder à l'outil, vous devez créer un compte.

Pour créer un compte, allez dans la [Matrice Salariale](https://www.salarymatrix.idhtrade.org/). &#x20;

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-01-21 a les 19.05.11.png" alt=""><figcaption></figcaption></figure>

L'outil est actuellement disponible en anglais, espagnol, français, portugais et vietnamien. Vous pouvez sélectionner votre langue préférée en cliquant sur le bouton situé en haut à droite.

Si vous utilisez la Matrice Salariale pour la première fois, cliquez sur le bouton « _S'inscrire_ » en haut à droite pour créer un compte.

Saisissez une adresse e-mail et un mot de passe sécurisé. Nous vous recommandons d'utiliser une adresse e-mail professionnelle non liée à une personne en particulier. Cela garantit l'accès aux calculs, même en cas de changement de personnel.

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-01-21 a les 19.06.28.png" alt=""><figcaption></figcaption></figure>

Clickez sur _Suivant_

* Vous devrez ensuite confirmer la Déclaration de confidentialité. Vous devez faire défiler jusqu'à la fin de la déclaration et cliquer sur le bouton « _Accepter et s'inscrire_ ».
* Vérifiez votre adresse e-mail pour la confirmer.
{% endstep %}

{% step %}
### Se connecter

* Allez dans la [Matrice Salariale](https://www.salarymatrix.idhtrade.org/).
* Connectez-vous avec votre e-mail et votre mot de passe.&#x20;
* Si vous avez oublié votre mot de passe ou si votre mot de passe ne fonctionne pas, cliquez sur « _Mot de passe oublié_ ». Vous devriez recevoir un e-mail pour créer un nouveau mot de passe.
{% endstep %}
{% endstepper %}
