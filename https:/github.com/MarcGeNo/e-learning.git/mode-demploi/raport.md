# Raport

Le contenu de votre rapport dépendra des modules complémentaires sélectionnés.

L'en-tête du rapport comprend un résumé des données les plus pertinentes.

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-01-22 a les 20.21.57.png" alt=""><figcaption></figcaption></figure>

Les résultats sont présentés sous forme graphique, ce qui permet de visualiser facilement les catégories professionnelles/travailleurs dont la rémunération est supérieure ou inférieure au salaire minimum vital estimé, ainsi que la contribution des salaires, des primes et des avantages en nature à une rémunération mensuelle comparable.

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-01-22 a les 20.25.01.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Si vous constatez des erreurs dans les données saisies, vous pouvez rouvrir le calcul en cliquant sur les trois points en haut de la page et en sélectionnant « Rouvrir pour modifier ». Une fois les données corrigées, vous pouvez les soumettre à nouveau pour accéder au rapport final corrigé.
{% endhint %}

Si vous souhaitez partager votre rapport, cliquez sur le bouton « Partager le rapport » situé à côté des trois points, pour le télécharger au format PDF ou Excel.

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-01-22 a les 20.26.55.png" alt=""><figcaption></figcaption></figure>
