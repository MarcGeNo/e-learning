# Sélection de l'estimation du salaire vital

Ensuite, vous devrez choisir une estimation du salaire vital pour votre région et la période de déclaration.

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-01-22 a les 18.55.51.png" alt=""><figcaption></figcaption></figure>

En cliquant sur le bouton _Sélectionner estimation du salaire vital_, l'outil vous fournira une liste des estimations disponibles correspondant à la période de rapport pour votre pays ou votre région, calculée selon des méthodologies reconnues par l'IDH.&#x20;

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-02-02 a les 12.00.53.png" alt=""><figcaption></figcaption></figure>

Vous pouvez utiliser les options de filtre pour faciliter votre recherche.&#x20;

{% hint style="info" %}
Si aucune estimation ne figure dans la liste, veuillez vérifier que vos filtres sont corrects.

Si les filtres sont corrects et qu'aucune estimation n'est encore disponible pour votre région, veuillez contacter les [méthodologies reconnues par l'IDH](https://www.idhsustainabletrade.com/idh-living-wage-identifier/) pour savoir leur disponibilité pour estimer le salaire vital dans votre région d'intérêt.
{% endhint %}

Plusieurs estimations de salaires de référence sont disponibles. Lors de votre choix, tenez compte des points suivants :

1. **Région** : Choisissez une estimation qui couvre votre région. Certaines estimations peuvent concerner un produit spécifique (par exemple, le café ou les bananes). Elles restent pertinentes pour tous les secteurs, car le salaire vital n’est pas sectoriel.
2. **Année** : Sélectionnez l’année correspondant à vos données salariales.
3. **Disponibilité** (publique ou payante) : Il y a des estimations de référence accessibles au public et gratuites pour la plupart des régions.
4. **Méthodologie** : Toutes les méthodologies incluses dans la Matrice des salaires ont été reconnues par l’IDH sur la base de 12 critères.

Si vous sélectionnez une méthodologie Anker (Full-fledged or Reference value) ou une estimation du Living Wage fo US, le montant mensuel brut estimé sera automatiquement intégré à l'outil. Si vous sélectionnez une autre méthodologie, vous devrez saisir la valeur manuellement..&#x20;

* Vous pouvez consulter les estimations publiques du LivingWageForUS [ici](https://www.google.com/maps/d/u/0/viewer?mid=1QFTe0iAk7LGj_tsjDAC8gfm-78a4bQA\&femb=1\&ll=50.688883235458384%2C-112.8810171778265\&z=3).
* Vous pouvez accéder aux estimations publiques du Wage Indictor [ici](https://wageindicator.org/salary/living-wage/workers-trade-unions). Si vous avez besoin d'accéder à d'anciens devis, vous pouvez demander l'accès à leur base de données payante [ici](https://wageindicator.org/work/living-wages/purchase-data/).
* Vous pouvez demander l'accès à la base de données du Fair Wage Network [ici](https://fair-wage.com/living-wage-database/).

Si vous souhaitez comparer la rémunération totale comparable à d'autres références au-delà d'une estimation de salaire vital, vous pouvez ajouter jusqu'à deux références supplémentaires de votre choix. La ou les références ne seront pas utilisées pour les calculs mais seront affichées visuellement dans le graphique de votre rapport.
