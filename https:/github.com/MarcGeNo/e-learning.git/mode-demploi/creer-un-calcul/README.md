# Créer un Calcul

Vous pouvez créer un « Calcul d'écart de salare vital » depuis la _vue Installations_ ou depuis la vue _Calculs_.

Dans la vue _Installations,_ cliquez sur l'établissement choisi et après cliquez sur le bouton _Créer un calcul d'écart_.

Dans la vue Calculs, cliquez sur le bouton _+ Calcul d'écart de salarie vital._
