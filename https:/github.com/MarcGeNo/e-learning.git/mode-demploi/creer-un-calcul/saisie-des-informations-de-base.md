# Saisie des informations de base

Lorsque vous créez un calcul d'écart de salarial vital, il vous sera demandé d'entrer les informations de base de l'établissement :

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-01-22 a les 18.47.39.png" alt=""><figcaption></figcaption></figure>

#### Établissement

Sélectionnez un établissement dans la liste déroulante ou cliquez sur _Nouveau établissement_ si vous n'en avez pas encore créé.

#### Année de rapport

L'IDH recommande d'utiliser une période de rapport d'une année civile complète. Cependant, certains systèmes de certification peuvent vous demander d'utiliser une année de production à la place. Par conséquent, si vous utilisez cet outil à des fins de certification, veuillez confirmer auprès du schéma de certification la période de déclaration à utiliser.

#### Nombre minimum de congés annuels payés pour un travailleur&#x20;

Saisissez ici le nombre d'heures de congé annuel et de jours fériés annuels payés (sauf les jours de repos hebdomadaires) auxquels un travailleur a droit légalement chaque année. Ce chiffre est utilisé par l'outil pour calculer le nombre maximal d'heures de travail régulières durant l'année de référence (année de travail standard corrigée).

#### Nombre d'heures de congé obligatoire non payé pour un travailleur&#x20;

Complétez ce champ uniquement si TOUS les travailleurs sont renvoyés chez eux sans solde pendant une certaine période. Cela peut se produire en cas d'urgence, comme un incendie, ou si l'établissement est fermé pour des raisons d'inondation, d'entretien ou d'autres circonstances.

Saisissez ici le nombre annuel d'heures de congé obligatoire non payé qu'un travailleur a été obligé de prendre. Par exemple, si TOUS les travailleurs ont été renvoyés chez eux sans salaire pendant deux semaines et que les heures de travail hebdomadaires habituelles sont de 48 heures, il y a 96.

Le congé obligatoire non payé n'inclut pas les jours de repos hebdomadaires.

#### Données requises pour avancer

L'outil est conçu pour travailler avec des données réelles sur les heures travaillées et la rémunération versée au cours d'une année complète. Par conséquent, pour obtenir des calculs précis, l'outil vous demandera de confirmer que vous disposez des données nécessaires pour avancer. Vous ne pouvez continuer à saisir les données que si vous cochez les deux cases ci-dessous :&#x20;

#### C’est un test:

Cliquez cette case si vous faites un calcul à des fins de test. Cela empêchera que les données soient envoyées à la base de données IDH lors de la soumission du calcul.
