# Vérifications des calculs

Avant de soumettre votre calcul, vous pourrez examiner les valeurs calculées.

L'outil vous fournira un graphique illustrant les niveaux de salaire actuels comparés à l'estimation du salaire vital, séparé par sexe. Les points de référence supplémentaires seront également indiqués dans le graphique.&#x20;

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-06-05 a les 10.12.48.png" alt=""><figcaption></figcaption></figure>

Vous pouvez cliquer sur n'importe quelle barre du graphique pour ouvrir un panneau à droite décrivant en détail comment les Salaries, Bonus et Avantages en nature ont été calculés.&#x20;

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-06-05 a les 10.14.19.png" alt=""><figcaption></figcaption></figure>

Après avoir examiné les calculs, vous pouvez confirmer de continuer.

{% hint style="info" %}
Vous pouvez trouver plus d'informations sur les formules de calcul de la Matrice Salariale[ ici](../../a-propos-de-la-matrice-salariale/formules-de-calcul.md).
{% endhint %}
