# Catégories d'emploi ou Travailleurs individuels

Vous pouvez saisir les employés par catégories d'emploi, individuellement ou en combinant les deux.

{% hint style="info" %}
Pour saisir les employés individuellement, créez une catégorie d'emploi contenant un seul employé.
{% endhint %}

<details>

<summary>Saisie de données de paie par catégorie d'emploi</summary>

Il est recommandé de saisir les données de paie par catégories d'emploi pour les établissements utilisant un système de rémunération simple basé sur le temps.

Si vous choisissez cette option, vous devrez calculer la moyenne des données de paie. Pour ce faire, additionnez les données de tous les employés et divisez le résultat par le nombre d'employés dans la catégorie.

_Par exemple : s'il y a 20 employés dans une catégorie, pour saisir les heures travaillées, additionnez leurs heures et divisez la somme par 20._

Bien que le regroupement des employés par catégories d'emploi puisse réduire le temps de saisie, il est important de s'assurer qu'il n'existe pas de variations importantes de salaires, de primes et d'avantages en nature entre les employés d'une même catégorie, car des informations importantes pourraient être omises en raison du calcul de la moyenne.

{% hint style="info" %}
Il est recommandé de saisir individuellement les données des employés rémunérés à la productivité, compte tenu des variations de rémunération propres à ce type de système.&#x20;
{% endhint %}

Par conséquent, les travailleurs inclus dans une même catégorie d'emploi doivent :

* Avoir le même type de contrat
* Effectuer un travail similaire
* Avoir le même horaire de travail
* Bénéficier de la même protection de convention collective
* Avoir perçu des salaires sensiblement équivalents (écart inférieur à 10 %)
* Avoir une productivité similaire
* Avoir perçu sensiblement les mêmes primes
* Avoir perçu sensiblement les mêmes avantages en nature

Pour faciliter le processus de vérification, utilisez un nom de catégorie d'emploi qui reflète le rôle des travailleurs inclus dans cette catégorie.

</details>

<details>

<summary>Saisie des données par employé</summary>

La saisie individuelle des employés est l'option recommandée. Elle permet d'importer les informations directement depuis le système de paie, sans avoir à calculer de moyennes. De plus, elle offre un rapport très détaillé avec une analyse au cas par cas.

Dans ce cas, pour faciliter la saisie des données, il est fortement recommandé d'utiliser le tableur Excel. Bien que la saisie d'une longue liste d'employés dans le fichier Excel puisse prendre un certain temps au départ, la mise à jour annuelle des informations est plus simple que le regroupement des employés par catégorie professionnelle, car il n'est pas nécessaire de recalculer les moyennes.

Pour assurer la traçabilité de chaque employé, le champ « Catégorie d'emploi » peut être utilisé pour inclure un identifiant d'employé ainsi que la catégorie d'emploie. Par exemple :

* Emballage – 12345
* 12345 – Emballage

{% hint style="info" %}
Veillez à ne pas utiliser de données personnelles comme identifiant !
{% endhint %}



</details>
