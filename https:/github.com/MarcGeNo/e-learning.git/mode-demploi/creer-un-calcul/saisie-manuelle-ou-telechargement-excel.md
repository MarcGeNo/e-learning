# Saisie manuelle ou télechargement Excel

### Saisie de données de paie

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-01-22 a les 19.19.07.png" alt=""><figcaption></figcaption></figure>

Vous pouvez saisir les données de paie manuellement dans l'outil ou à l'aide du modèle Excel.

<details>

<summary>Saise Manuelle</summary>

Pour saisir les données de paie manuellement, cliquez sur le bouton « _+ Ajouter une catégorie d'emploi_ ».

Lorsque vous saisissez manuellement vos données de paie, l'outil affiche l'état de la saisie grâce à une étiquette colorée située à droite du menu supérieur.

Pour enregistrer vos données, vous devez saisir au minimum :

* Nom de la catégorie d'emploi
* Nom de la zone du travail
* Nombre d'hommes et/ou de femmes
* Moyenne des heures travaillées par les hommes et/ou les femmes
* Salaire moyen des hommes et/ou des femmes

{% hint style="info" %}
Une fois ces informations saisies, l'étiquette affichera « Terminé » et vous pourrez enregistrer la catégorie d'emploi. Veuillez noter que vous devrez peut-être encore saisir les heures supplémentaires, les primes et les avantages en nature, le cas échéant.
{% endhint %}

</details>

<details>

<summary>Saise a l'aide du modèle Excel</summary>

{% hint style="info" %}
Téléversez toujours le modèle Excel depuis la plateforme pour vous assurer d'utiliser la dernière version.
{% endhint %}

{% hint style="info" %}
Ne modifiez pas le format du fichier téléversé, sinon il ne pourra pas être téléchargé.
{% endhint %}

Renseignez une ligne par catégorie professionnelle et par sexe.

Une fois votre fichier Excel rempli, cliquez sur « _Télécharger un Excel_ » et sélectionnez le fichier sur votre ordinateur.

En cas de problème lors de l'importation du modèle, consultez la section « Dépannage »[ ici](../../informations-complementaires/depanage.md).

</details>
