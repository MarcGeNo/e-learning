# Ingreso de la Información básica

Al crear un Cálculo de la brecha de salario digno, se le pedirá que introduzca la información básica siguiente para la Instalación:

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-01-20 a les 16.43.59.png" alt=""><figcaption></figcaption></figure>

#### Instalación:&#x20;

Seleccione una instalación de la lista desplegable o haga click en _Nueva instalación_ si todavía no la creó.

#### Año de los datos:&#x20;

IDH recomienda utilizar un periodo salarial de un año calendario completo. Sin embargo, algunos esquemas de certificación pueden pedirle que use un año de producción. Por lo tanto, si utiliza la herramienta con fines de certificación, por favor confirme con el esquema de certificación el periodo de datos a utilizar.

Si selecciona un año de los datos para el cual ya existe un Cálculo, aparecerá el siguiente mensaje: _"Ya existe un cálculo de brechas de salario digno para esta instalación y año de los datos"._ En este caso, _&#x73;_&#x6F;lamente podrá crear un nuevo cálculo para una instalacion y año indicando más abajo que se trata de un cálculo de prueba.

#### Número mínimo de vacaciones anuales remuneradas para un trabajador:

Aquí se ingresa el número de horas de vacaciones anuales y festivos anuales remuneradas (pero excluyendo los días de descanso semanales) a las que un trabajador tiene derecho legalmente como mínimo cada año. Esta cifra es utilizada por la herramienta para calcular el número máximo de horas de trabajo regulares en el año de los datos (año laboral estándar corregido).

#### Número de horas de baja obligatoria sin sueldo para un trabajador:

Solo se debe completar este campo si TODOS los trabajadores son enviados a casa sin sueldo durante un determinado periodo. Esto puede ocurrir si la instalación sufre una emergencia, como un incendio, o si está cerrada para trabajar por inundaciones, mantenimiento u otras circunstancias.

Aquí se indica el número anual de horas de permiso obligatorio no remunerado que un trabajador se ha visto obligado a tomar. Por ejemplo, si TODOS los trabajadores fueron enviados a casa sin sueldo durante dos semanas y las horas semanales regulares de trabajo son 48, entre 96.

La baja obligatoria no remunerada no incluye días de descanso semanales.

#### Datos necesarios para avanzar

La herramienta está diseñada para trabajar con datos reales de horas trabajadas y remuneraciones pagadas durante un año completo. Por lo tanto, para obtener cálculos precisos, la herramienta le pedirá que confirme que tiene los datos necesarios para continuar.
