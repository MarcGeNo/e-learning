# Crear un Cálculo

Puede crear un _"Cálculo de la brecha de salario digno"_ desde la vista _Instalaciones_ o desde la vista _Cálculos_.

En la vista _Instalaciones_, haga clic en la instalación correspondiente y pinche en el botón _Crear Cálculo de Brecha de salario digno_.

En la vista _Cálculos_, haz clic en el botón _+ Crear cálculo de brecha de salario digno._
