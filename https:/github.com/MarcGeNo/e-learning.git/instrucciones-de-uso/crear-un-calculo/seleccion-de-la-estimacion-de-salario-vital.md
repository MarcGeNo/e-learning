# Seleccion de la estimación de salario vital

A continuación, deberá seleccionar una estimación del salario vital para su región y periodo de los datos.

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-01-20 a les 16.45.47.png" alt=""><figcaption></figcaption></figure>

Al hacer clic en el botón _Seleccionar estimación de referencia_, la herramienta le proporcionará una lista de estimaciones disponibles, correspondientes al año pasado, actual y siguiente del periodo de los datos para su país o región, calculadas mediante metodologías reconocidas por la IDH.&#x20;

<figure><img src="../../.gitbook/assets/Captura de pantalla 2026-02-02 a les 11.57.28.png" alt=""><figcaption></figcaption></figure>

Puede haber varios valores estimados de referencia disponibles. Al elegir, preste atención a:

1. **Región**: elija una estimación que cubra su región. Algunas estimaciones pueden referirse a un producto específico (por ejemplo, café o banano). Estos siguen siendo relevantes para cualquier sector , ya que los salarios dignos no son sectoriales.
2. **Año**: seleccione el año correspondiente a sus datos salariales.
3. **Disponibilidad** (pública o de pago): existen estimaciones de referencia públicamente disponibles de forma gratuita para la mayoría de las regiones.
4. **Metodología**: indica la metodología de estimación. Todas las metodologías incluidas en la Matriz Salarial han sido reconocidas por IDH en base a 12 criterios.

Puede usar las opciones de filtro para facilitar la búsqueda.&#x20;

{% hint style="info" %}
Si no hay estimaciones en la lista, verifique que sus filtros sean correctos.

Si los filtros son correctos y todavía no hay estimaciones disponibles para su región, comuníquese con las metodologías reconocidas por IDH para averiguar si están interesadas en estimar el salario digno de su región de interés.
{% endhint %}

Si selecciona una estimación realizada mediante la metodología Anker (Full-fledged o Reference values) o por Living Wage for US, el valor estimado bruto mensual se incluirá automáticamente en la herramienta. Si selecciona alguna de las otras metodologías, tendrá que ingresar el valor manualmente.&#x20;

Puede acceder a las estimaciones públicas de Living Wage for US [aquí](https://www.google.com/maps/d/u/0/viewer?mid=1QFTe0iAk7LGj_tsjDAC8gfm-78a4bQA\&femb=1\&ll=50.688883235458306%2C-112.8810171778265\&z=3).

Puede acceder a las estimaciones públicas de Wage Indicator [aquí](https://wageindicator.org/salary/living-wage/workers-trade-unions). Si necesita acceder a estimaciones antiguas, puede solicitar acceso a su base de datos de pago [aquí](https://wageindicator.org/work/living-wages/purchase-data/).

Puede solicitar acceso a la base de datos de Fair Wage Network [aquí](https://fair-wage.com/living-wage-database/).

Si desea comparar la remuneración total comparable con otras referencias más allá de una estimación de salario digno, puede añadir hasta dos referencias adicionales. La(s) referencia(s) no se utilizarán para ningún cálculo, pero se mostrarán visualmente en el gráfico del informe.
