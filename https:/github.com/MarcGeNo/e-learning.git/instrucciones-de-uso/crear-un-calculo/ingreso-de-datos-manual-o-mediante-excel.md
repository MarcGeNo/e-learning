# ¿Ingreso de datos manual o mediante Excel?

## Sistema de ingreso de datos

Puede ingresar los datos de la nómina manualmente en la herramienta o usando la plantilla de Excel.

Para ingresar la nómina manualmente, haga clic en el botón _+ Añadir categoría laboral_.

Para ingresar la nómina usando la plantilla de carga de Excel, descargue la plantilla más reciente, complete los datos y cárguela en la herramienta haciendo clic en los botones correspondientes.

<details>

<summary><strong>Ingreso manual de datos</strong></summary>

Cuando ingrese los datos de la nómina manualmente, la herramienta le mostrará el estado de su entrada de datos mediante una etiqueta coloreada a la derecha del menú superior:

Para poder guardar los datos tiene que introducir al menos:

* Nombre de la Categoría laboral
* Nombre del Área de trabajo
* Número de hombres y/o mujeres
* Promedio de las horas ordinarias trabajadas de hombres y/o mujeres
* Salario medio ganado de hombres y/o mujeres

{% hint style="info" %}
Una vez introducida esta información, la etiqueta de estado cambiará a _Completado_ y podrá guardar la categoría laboral, pero tenga en cuenta que todavía deberá introducir horas extra, bonificaciones y beneficios en especie cuando corresponda.
{% endhint %}

</details>

<details>

<summary><strong>Carga mediante fichero Excel</strong></summary>

{% hint style="info" %}
Descargue siempre la plantilla de Excel desde la plataforma para asegurarse de que tiene la última versión.
{% endhint %}

{% hint style="info" %}
No haga ningún cambio en el formato del archivo descargado, de lo contrario el archivo no se cargará.
{% endhint %}

Complete una fila por categoría laboral/trabajador por género.

Una vez completado el Excel, haz clic en Subir plantilla _Excel_ y seleccione el archivo desde su ordenador.

Si tiene problemas para cargar los datos, consulte la sección de solución de problemas [aquí](../../informaciones-adicionales/solucion-de-problemas.md).



</details>
